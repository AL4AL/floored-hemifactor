# Research plan

Target artifact: `gemma4:12b` (local Ollama / GGUF), chassis in [hardware.md](hardware.md). Theory in [theory.md](theory.md).

**Binding:** [hard-constraints.md](hard-constraints.md) — read before every phase exit. LLM-typical mistakes (lossless 6 GB, UVM=GDDR, chat-vibe passes, citing KV “50%” as weight 50%, etc.) are listed there.

## Guiding rules

1. **Hardware and transistors only** as hard limits — no obligation to ship inside Ollama.
2. **Do not claim 2×** until spectrum + held-out bars clear (constraints D1, E table).
3. Prefer **negative results written down** over silent retreat into smaller quants.
4. Calibrate from **this model’s own activations**; hold out text the fit must not see (C3).
5. Byte accounting includes chart/tail **rereads**, KV, scratch (A4, B3, D4).
6. Run `python -m hemifactor.cli lint-claim "..."` on any draft success sentence.

## Phase 1 — Measure `D` and `Σ` (week-scale)

**Goal:** quantify the error budget Q4 already paid, and the residual covariance per layer.

1. Stream a few hundred sequences, length 512–1024:
   - generated by this model, **plus**
   - a small held-out text corpus forbidden to the fit.
2. Maintain Welford (or sketched) covariance per layer for residual inputs: `3840×3840` — ~6 GB FP64 for all 48 if kept dense; sketch/downsample if needed.
3. Optionally sketch covariance of the SwiGLU intermediate (`15360`).
4. Dequantize one layer at a time to FP16 (~hundreds of MB) and record activation MSE of stored codes vs higher-rate copy where the tensor is Q6.
5. **Control bar:** requantize one Q6 down-projection to Q4; measure held-out perplexity / NLL delta. That delta is the end-to-end quantum of “real” loss.

**Exit artifacts**

- `artifacts/D_per_tensor.json`
- `artifacts/participation_ratio_per_layer.json` (`tr(Σ)² / ‖Σ‖_F²`)
- `artifacts/q6_to_q4_control.json`

**Pass/fail for continuing:** control bar is finite and stable; covariances estimable on this RAM budget.

## Phase 2 — Whitened spectrum (hours–days on CPU)

**Goal:** decide whether low-rank hemifactor is licensed.

1. Eigendecompose each `3840×3840` Gram (or use randomized SVD on whitened maps).
2. Plot discarded energy `Σ_{i>k} σ_i²` vs `D` at candidate ranks:
   - charted maps: `k ∈ {1536, 1700, 1920, …}`
   - two-sided MLP: `k ∈ {1024, 1536, 1920, …}`
3. Per role, per layer (at least: down, gate, up, q, o).

**Decision tree**

| Observation | Action |
|---|---|
| Tail energy ≤ `D` at `k` that yields ≤ ~0.5–0.55× bytes | Proceed Phase 3 (hemifactor) |
| Participation ratio ~1500–2500 | Borderline; proceed with honest traffic report |
| Participation ratio ~3800 / flat spectrum | **Branch B:** Monarch/butterfly fit on `(x, Wx)`; skip pure SVD truncate |
| Layer residuals need ≫ 4 shared atoms | Drop rich shared tail; keep per-matrix `k` only |

**Exit artifacts**

- `artifacts/spectra/*.png` + tables
- `artifacts/rank_license.md` (go / branch-B / stop)

## Phase 3 — Single-role prototype (down projections)

**Goal:** one role clears quality + byte bars before touching the whole net.

1. Reconstruct `AB` from whitened SVD (or Monarch factors if Branch B).
2. Quantize factors to 4–6 bits (match “spend bits on kept components”).
3. Run held-out perplexity with **all other tensors untouched**.
4. Pass if:
   - PPL/NLL move ≤ Q6→Q4 control from Phase 1, **and**
   - down-projection bytes ≤ **½** of baseline down-projection bytes (or documented 0.55× with reason).

**Fail:** do not “fix” by lowering bits on the rest of the model. Record spectrum vs `D` gap.

**Exit:** `artifacts/down_proj_prototype/` (factors, metrics, config).

---

## Phase 4 — Fuse and time the bus

**Goal:** prove the memory story on the 3050, not only parameter counts.

1. Implement one fused CUDA (or Triton) path: read factors → write activations; **never** materialize dense `W` in GDDR.
2. Log memory clocks at **60 W** (current default) and **95 W** if firmware allows.
3. Compare measured tok/s (microbenchmark of the patched role, then fuller stack) to

   ```text
   168e9 / (factor_bytes + chart_reread + tail_reread + kv_bytes)
   ```

4. Extend role-by-role only where Phase 2 licensed the rank.

**Early stop (still valuable):** if the `k` that meets `D` only reaches ~**0.7×** traffic — that can still be the **residency prize** (fit line ~0.78×). Report as residency without claiming speed doubling.

## Phase 5 — Full-model assembly (only after Phase 3–4)

1. Apply licensed roles; keep embedding strategy explicit (untouched Q6 vs mild factor).
2. Fix SWA KV at window 1024; set global-KV watermark so GDDR stays inside 6 GB.
3. End-to-end: short-context decode tok/s, held-out PPL, optional smoke chat quality.
4. Write `docs/results.md` with pass/fail against the success predicate in theory.md §7.
